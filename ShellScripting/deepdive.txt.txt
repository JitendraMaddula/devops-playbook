Shell Scripts:
To perform repititive tasks, Instead of running each individual command manually one after the other - We can write them in a file called as Shell Script
The extension of Shell Script is .sh
Executing Shell Scripts:
1. ./<name>.sh --- Recommended
2. bash <name>.sh --- Simple but uses BASH Shell Only for executing commands

Shebang:
The first line of any Shell Script should always start with Shebang
#!/bin/bash
Shebang invokes the bash shell and if it is not used inside the script, The shell script gets executed in the default shell of the server

Variables:
Variables are strings to which we can assign some value. The value could be an integer, string, sentence, file name or any other data
But the name of the variable can only contain letters, numbers and underscore
To get the value that is stored inside the variable, Add $ followed by the variable name

Arguments:
To reference the arguments passed to the shell script at run time - we can use $1, $2, $3 ...... $(10) ....$(n)
Example - ./<script>.sh <first-argument> <second-argument>

bashrc -- These are auto executable files that execute everytime an user logs in to the server or a new shell session starts. 
bash_profile -- They are generally user for setting up Aliases, Environment Variables etc
bash_logout -- Auto Executable file that executes everytime a session is exited or killed
bash_history -- It contains all the commands executed by the user
history -- Command to show history of commands executed by the user

Difference between bashrc and bash_profile
.bashrc file is executed every time you open a new terminal window or tab after you have already logged in.
.bash_profile file is executed only once when you first log into your system.

Special Variables:
$0 -- The Name of the Shell Script
$# -- THe Total Number of Arguments Passed to the script
$* -- All the Arguments passed to the script in String Format
$@ -- All the Arguments passed to the script in Array Format
$$ -- The PID of the current Running Process
$? -- The status of the last executed command
$! -- PID of the last background process

    echo "$num2 is the biggest"

    echo "$num3 is the biggest"

2. Check whether given input is Link, File, Directory
#!/bin/bash
echo "Enter the name of a link or file or directory"
read name
if [ -L $name ]; then
    echo "$name is a Softlink"
elif [ -f $name ]; then
    echo "$name is a file"
elif [ -d $name ]; then
    echo "$name is a directory"
else
    echo "$name is neither a link, a file, nor a directory."
fi

Script - Find the sum of Even And Odd Numbers upto N
#!/bin/bash
echo "Enter the N value"
read n
even=0
odd=0
while [ $n -gt 0 ]
do  
    if [ $(($n%2)) -eq 0 ]; then
        even=$(($even+$n))
    else
        odd=$(($odd+$n))
    fi
    ((n--))   
done
echo "The Sum of Even Numbers is $even"
echo "The Sum of Odd Numbers is $odd"

Debugging in Shell Scripts:
    set -x --> To print commands and their arguments as they are executed
    set -e --> Exits the shell script immediately, if a command exits with non zero status
    set -u: Stops the script immediately if you try to use a variable that doesn't exist yet.
    set -n: Scans your script for formatting errors without actually executing any of the commands.

Practical Example: Find all the files that are created more than 30 days ago - Archive those files and delete them
#!/bin/bash
archive_name=backup_$(date +%d%m%Y-%H%M).tar.gz
logs_folder="/home/ec2-user/logs"
backups_folder="/home/ec2-user/logs/backups"
mkdir -p $backups_folder
cd $logs_folder
find -type f -mtime +30 | tar -czf $backups_folder/$archive_name -T -
if [ -f $backups_folder/$archive_name ]; then
    echo "Tar Archive has been Successfully Created at $backups_folder/$archive_name"
    find -type f -mtime +30 -delete
    echo "Files older than 30 days are deleted Successfully"
else
    echo "No Files found for Archiving"
fi

For Loop Syntax:

1. C-Style 
for ((Init; Condition; Iteration))
do
    Commands
done

2. List Iterative Loop
a. With Direct Values
for i in var1 var2 var3 var4 ..... varn
do
    commands
done

b. Using Range Functions:
for i in {0..10}    -- The value of i will iterate from 0 to 10
for i in {0..10..2} -- The value of i will iterate from 0 to 10 with increments of 2

c. Using Sequence Command
for i in $(seq 0 10)    -- The value of i will iterate from 0 to 10
for i in $(seq 0 2 10)  -- The value of i will iterate from 0 to 10 with increments of 2

d. Using Arguments
for i in $* -- The value of i will iterate through all the arguments passed to the shell script
for i in $@ -- The value of i will iterate through all the arguments passed to the shell script

Script: Check whether particular services on the server are running or not [docker jenkins kubelet]
#!/bin/bash
for i in docker jenkins kubelet
do
    systemctl is-active -q $i
    if [ $? -ne 0 ]; then
        echo "Service $i is In-Active!!!!!!" >> services.txt
        sudo systemctl start $i
    fi
done
if [ -f services.txt ]; then
    mail -s "Services Stopped" adithya@gmail.com < services.txt
    rm services.txt
fi

Case Statements:
Syntax:
case $<var> in
    pattern1) Commands to be executed if variable matches pattern1;;
    pattern2) Commands to be executed if variable matches pattern2;;
    pattern3) Commands to be executed if variable matches pattern3;;
    pattern4 | pattern5) Commands to be executed if variable matches pattern4 or pattern5;;
    *) Commands to be executed if none of the above patterns match;;
esac

Script: Check the number entered by an user to show difference btwn if-else-if and case
1. IF-ELSE-IF
#!/bin/bash
echo "Enter the Number Between 0-5"
read n
if [ $n -eq 0 ]; then
    echo "The Number entered by the user is Zero"
elif [ $n -eq 1 ]; then
    echo "The Number entered by the user is One"
elif [ $n -eq 2 ]; then
    echo "The Number entered by the user is Two"
elif [ $n -eq 3 ]; then
    echo "The Number entered by the user is Three"
elif [ $n -eq 4 ] || [ $n -eq 5 ] || ; then
    echo "The Number entered by the user is Four or Five"
else
    echo "Invalid Number"
fi

    1) echo "The Number entered by the user is One";;
    2) echo "The Number entered by the user is Two";;
    3) echo "The Number entered by the user is Three";;

Buckets or brackets and there Primary Purpose
$() (Command Substitution)  : Runs the command inside and returns the output (e.g., date=$(date)).
${} (Parameter Expansion)   : The standard way to reference variables. It allows for advanced manipulation (like ${str,,} or ${str:0:1}).
(()) (Arithmetic Expansion) : Evaluates math expressions. Crucial: It handles integer math and logic, not strings.
() (Subshell)               : Runs the commands inside in a separate, "child" shell environment. Changes made here (like cd or variable exports) don't affect your main script.
[[]] (Extended Test)        : The "modern" way to test conditions. It supports regex (=~) and logical &&/||.
[] (Test)                   : The "legacy" way. Strict, POSIX-compliant, but lacks the features of [[]].
<< / <<<                    : Feed input to a command (Piping)
