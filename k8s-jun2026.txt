Manifest files fileds1. API version
It is used to define the version of api kubernetes uses to create an object.

2. Kind
It specifies the type of kubernetes object being created. 

	3. Metadata
It is used to set information about the object we are creating like name of the object/pod, labels to be used for the object namespace and annotations 

4. Labels
These are key value pairs attached to kubernetes objects for identification and grouping, commonly used by services and selectors

5.Selectors
They are used to identify kubernetes objects using there labels.
There are two types of selectors in kubernetes1. Equity-based selectors
Used to identify objects by exact and key and value.
2. Set based selectors
Used to identify objects by keys based on set of values.

6.State
This is used to define the core information that is the desired state of the kubernetes object


Pod phases/Lifecycles
1.Pending
The pod has been accepted by kubernetes cluster but it is not yet running.
2.Running
The pod is scheduled on a node and alll the containers have been created.
3. Succeeded/Completed
All the containers in the pod have terminated in success that is containers exited with 0 exit code
4. FailedAll the containers in the pod have terminated but atleast one container exited with non-zero exit code 
5.Unknown
the state could not be determined due to an error in communication with the nod where the pod was running
